# GatherOS

A local-first macOS app for saving, browsing, and organizing visual inspiration.

Capture screenshots (area, fullscreen, or window), drag-and-drop images from
anywhere, or paste from clipboard — all saved instantly to a local SQLite
database with auto-generated color tags, AI-powered search, and smart
deduplication.

## Features

- Screen capture (⌘⇧S) with floating capture UI
- Organize with moodboards, tags, and favorites
- AI search via OpenAI or Gemini (your own API key — stored locally)
- Drag-and-drop from browser, Finder, or anywhere
- Services menu integration for save-from-anywhere workflow
- Local-first: everything stays on your machine

## Built with

Electron + Vite + better-sqlite3 + sharp
